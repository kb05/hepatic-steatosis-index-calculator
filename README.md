# Steatosis Index Calculator

This is a quick prototype of a simple application that helps doctors calculate hepatic steatosis and fibrosis indices.

It was created with AI, with one goal: to make it easier for doctors to assess and diagnose this disease.

## What it calculates

- **FLI** (Fatty Liver Index)
- **HSI** (Hepatic Steatosis Index)
- **FIB-4** (Fibrosis-4)
- **APRI** (AST to Platelet Ratio Index)
- **NFS** (NAFLD Fibrosis Score)

Each result shows its value and its interpretation range.

## Features

- Results update as you type.
- Spanish and English interface.
- **Print report** opens the print dialog with a clean report, which you can print or save as a PDF.

## How to use

Open `index.html` in a web browser. No installation, build step, or server is needed, and all calculations run in the browser.

To publish it, upload the project files (`index.html`, `styles.css`, `calculator.js` and `favicon.svg`) to any static web hosting service.

## Disclaimer

This is a prototype support tool. It does not replace clinical judgment, and results should always be interpreted by a qualified professional.
